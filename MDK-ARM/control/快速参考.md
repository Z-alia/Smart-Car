# 快速参考 - 模块整合后的调用方式

## 一行代码完成控制

```c
// 在1ms定时器中断中调用
control_execute(1.0f);  // 前进速度1.0m/s
```

## 完整示例（最简版）

```c
// main.c
#include "control.h"
#include "image.h"
#include "motor.h"

int main(void)
{
    // 初始化
    HAL_Init();
    cam_err_init(20, 80, 10, 100);
    control_init_cascade_pid_default();
    HAL_TIM_Base_Start_IT(&htim_control);
    
    while(1)
    {
        if (new_image_ready) {
            image_process();  // 更新边线
            new_image_ready = 0;
        }
    }
}

// 1ms控制中断
void TIM_Control_IRQHandler(void)
{
    // 更新编码器
    control.lencoder_count_last = control.lencoder_count;
    control.rencoder_count_last = control.rencoder_count;
    control.lencoder_count = TIM_LEFT_ENCODER->CNT;
    control.rencoder_count = TIM_RIGHT_ENCODER->CNT;
    
    get_speed();              // 计算速度
    control_execute(1.0f);    // 执行控制(图像→误差→控制→输出)
    motor_follow_line();      // 电机输出
}
```

## 数据流向（一图看懂）

```
image_process()
    ↓
l_border[120] / r_border[120]  ← 图像模块输出
    ↓
cam_err_calculation()          ← 自动读取边线数组
    ↓
err (横向误差)
    ↓
control_loop()                 ← PID/ADRC控制
    ↓
pwm_L / pwm_R
    ↓
control_execute()              ← 写入control结构体
    ↓
control.left_target_speed      ← 电机模块读取
control.right_target_speed
control.left_dir / right_dir
    ↓
motor_follow_line()            ← 硬件输出
```

## 关键数据结构

### control_t（全局共享）
```c
extern control_t control;  // 全局实例

// 包含内容:
control.left_speed           // 速度反馈(m/s)
control.right_speed
control.left_target_speed    // PWM输出(0~1000)
control.right_target_speed
control.left_dir             // 方向(1正,0反)
control.right_dir
```

### 外部边线数组（来自image.c）
```c
extern uint8_t l_border[120];
extern uint8_t r_border[120];
extern uint8_t left_lost[120];
extern uint8_t right_lost[120];
```

## 常见问题速查

| 问题 | 可能原因 | 解决方法 |
|-----|---------|---------|
| 误差为0 | 边线未更新 | 检查`image_process()`是否执行 |
| 电机不转 | PWM输出为0 | 检查控制参数是否过小 |
| 速度为0 | 编码器未更新 | 检查编码器计数是否变化 |
| 振荡严重 | PID参数过大 | 减小Kp和Kd |
| 反应迟钝 | PID参数过小 | 增大Kp |

## 重要提醒

✅ **必须按顺序调用**:
```c
get_speed();         // 先计算速度
control_execute();   // 再执行控制
motor_follow_line(); // 最后输出
```

✅ **控制周期必须为1ms**（与ADRC的h参数一致）

✅ **图像处理可以异步**，但必须在控制前完成

✅ **motor.c需要包含control.h**，才能访问`control`结构体
