### 步骤2：修改 act_persp.c

#### 2.1 包含头文件

#### 2.2 修改 persp_task 函数
在 `persp_task()` 函数中，计算完逆透视坐标后添加：

```c
void persp_task(int16 xl, int16 xr, int16 y)
{
    int16 oxl, oxr, oyl, oyr;
    
    // 限幅
    if(xl<0) xl=0;
    else if(xl>187) xl=187;
    if(xr<0) xr=0;
    else if(xr>187) xr=187;
    
    // 计算逆透视坐标
    oxl = get_persp_data_ox(xl, y);
    oyl = get_persp_data_oy(xl, y);
    oxr = get_persp_data_ox(xr, y);
    oyr = get_persp_data_oy(xr, y);
    
    // ========== 在这里添加（在原有代码之后）==========
    if (y >= 0 && y < 120) {
        persp_lx[y] = oxl;
        persp_ly[y] = oyl;
        persp_rx[y] = oxr;
        persp_ry[y] = oyr;
    }
    // ========== 添加结束 ==========
    
    // 原有的显示逻辑保持不变
    if (img_showmode == 2) {
        imo[y][l_border[y]] = 1;
        imo[y][r_border[y]] = 2;
    }
    // ... 后续代码不变 ...
}
```

## 常见错误及解决

### ❌ 编译错误："undefined reference to persp_lx"
**原因**: 忘记定义数组  
**解决**: 在 image.c 或 act_persp.c 中添加步骤1的代码

### ❌ 编译错误："persp_lx undeclared"
**原因**: act_persp.c 未包含 control.h  
**解决**: 在 act_persp.c 顶部添加 `#include "control.h"`

### ❌ 运行时所有逆透视坐标都是0
**原因**: persp_task() 未被调用或未填充数组  
**解决**: 
1. 确认 image_process() 中调用了 persp_task()
2. 检查填充代码是否添加到正确位置（在计算oxl/oyl之后）

### ❌ 控制效果与原版不一致
**原因**: forward_near/far 参数不合适  
**解决**: 调整参数
```c
cam_err_init(20, 80, 10, 100);  // 试试这组参数
//                    ^   ^
//                    |   +-- forward_far 调大看远处
//                    +------ forward_near 调小看近处
```
