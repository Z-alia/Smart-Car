**原版算法（act_persp.c）**：

## 数据流完整链路

```
image_process()
    ↓
边线识别 → l_border[y], r_border[y]
    ↓
persp_task(l_border[y], r_border[y], y)
    ↓
逆透视变换 → persp_lx[y], persp_ly[y], persp_rx[y], persp_ry[y]
    ↓

    ↓
计算边界点到车轮的切线斜率:
  angel_left = 125 × (persp_lx - camwl) / (persp_ly - camwf)

    ↓
误差 = AngleLeft + AngleRight
    ↓

```

## 公式详解

### 原版公式的物理意义

```c
angel_left = 125 × (persp_lx - camwl) / (persp_ly - camwf)
```

**几何解释**：
- `persp_lx, persp_ly`: 左边界点的逆透视坐标
- `camwl, camwf`: 左车轮的图像坐标
- `(persp_lx - camwl) / (persp_ly - camwf)`: 从车轮到边界点的斜率
- `× 125`: 缩放到合适的数值范围（原注释说×1000有误，实际×125）

**为什么是125而不是1000？**
根据原代码注释推测：
- 原始斜率单位可能经过某种归一化
- 125 可能是根据实际测试得出的最优缩放因子
- 使误差值落在合理范围（约±200）

### 与简化版的区别

**简化版**（已弃用）：
```c
angel_left = (l_border[y] - l_border[y-1]) × 1000
```
- 只看相邻行的边界变化
- 不考虑车轮位置
- 不使用逆透视坐标

**原版**（当前实现）：
```c
angel_left = 125 × (persp_lx[y] - camwl) / (persp_ly[y] - camwf)
```
- 计算边界点到车轮的实际切线角度
- 使用逆透视坐标（更准确的空间位置）
- 考虑车轮位置（物理意义更明确）
