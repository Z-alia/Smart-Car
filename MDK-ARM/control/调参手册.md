## 🚀 快速开始

### 第一步：选择控制方案

```c
// 在main函数中初始化
void main(void)
{
    // 硬件初始化...
    
    // 方案选择(二选一)
    control_init(CONTROL_SCHEME_CASCADE_PID);  // 推荐新手:串级PID
    // control_init(CONTROL_SCHEME_ADRC);      // 推荐进阶:ADRC
    
    while(1) {
        // 主控制循环
        float vL = get_left_speed();   // 获取左轮速度
        float vR = get_right_speed();  // 获取右轮速度
        float pwm_L, pwm_R;
        
        control_loop(1.0f, vL, vR, &pwm_L, &pwm_R);
        
        set_motor_pwm(pwm_L, pwm_R);
        delay_ms(1);  // 1ms控制周期
    }
}
```

### 第二步：确认基础参数
- **控制周期**：1ms (必须与代码一致)
- **编码器精度**：确保速度测量准确
- **PWM范围**：建议 [-1000, 1000]
- **前进速度**：建议从 0.5m/s 开始测试

## 🎯 方案一：串级PID调参

### 控制结构
```
图像误差 → 比例控制 → 差速目标 → 左右轮速度目标
                                    ↓
                              速度环PID → PWM
```

### 参数位置
在 `control.c` 的 `cascade_pid_init()` 函数中

---

### 📊 外环参数（差速映射）

#### 1. `speed_ratio` - 差速映射比例 ⭐⭐⭐⭐⭐
**物理意义**：图像误差转换为差速的比例系数

**默认值**：`0.01f`

**调节方法**：
1. **初始测试**（直道）
   - 设置 `speed_ratio = 0.005f`
   - 观察小车是否能回到中线
   - 如果几乎不转向 → 增大 2 倍
   - 如果左右晃动 → 减小一半

2. **响应速度调节**（弯道）
   - 弯道入弯慢 → 增大 20%（如 0.01 → 0.012）
   - 弯道振荡/冲出 → 减小 20%（如 0.01 → 0.008）

3. **最优值范围**：
   - 小弯道赛道：`0.008 ~ 0.015`
   - 大弯道赛道：`0.005 ~ 0.010`
   - 复杂赛道：`0.010 ~ 0.020`

**现象对照表**：
| 现象 | 原因 | 调节方向 |
|------|------|----------|
| 直道偏离中线不回正 | speed_ratio 过小 | 增大 1.5~2 倍 |
| 直道左右晃动 | speed_ratio 过大 | 减小到 0.5~0.7 倍 |
| 入弯慢/冲出赛道 | speed_ratio 过小 | 增大 10~20% |
| 弯道内振荡 | speed_ratio 过大 | 减小 10~20% |

---

#### 2. `max_diff_speed` - 最大差速限幅 ⭐⭐⭐⭐
**物理意义**：允许的最大左右轮速度差（m/s）

**默认值**：`1.5f`

**调节方法**：
1. **安全起步**：设置为前进速度的 1.5~2 倍
   - 前进速度 1.0m/s → max_diff_speed = 1.5m/s
   - 前进速度 0.5m/s → max_diff_speed = 0.75m/s

2. **性能优化**：
   - 急弯过不去 → 增大 20%
   - 急弯时打滑/失控 → 减小 20%

3. **经验公式**：
   ```c
   max_diff_speed = v_forward × 1.5;  // 激进
   max_diff_speed = v_forward × 1.0;  // 保守
   ```

---

#### 3. `smooth_alpha` - 平滑系数 ⭐⭐⭐
**物理意义**：速度目标的平滑过渡系数（0~1）

**默认值**：`0.20f`

**调节方法**：
- `0.1` - 非常平滑，响应慢（适合高速）
- `0.2` - 平滑适中（**推荐默认值**）
- `0.5` - 较快响应
- `1.0` - 无平滑，直接响应

**调节建议**：
- 高速行驶（>1.5m/s）→ 减小到 0.1~0.15
- 低速行驶（<0.8m/s）→ 增大到 0.3~0.5
- 出现高频抖动 → 减小到 0.1

---

#### 4. 非线性增益 (高级特性) ⭐⭐
**物理意义**：仿照 `cam_err_calculation` 的二次非线性增益

**公式**：`output = (1 + K·err²)·err`
- 小误差时接近线性
- 大误差时增益自动增大

**默认值**：
```c
enable_nonlinear = 0;      // 默认禁用
nonlinear_k = 1e-6f;       // 非线性系数
```

**何时启用**：
- ✅ 入弯慢，需要更激进的大误差响应
- ✅ 直道稳定但弯道不够快
- ✅ 对小误差的精细控制要求高

**何时禁用**：
- ❌ 新手调参阶段（增加复杂度）
- ❌ 高速行驶（可能引入振荡）
- ❌ 已经通过 `speed_ratio` 调好了

**调节方法**：
1. 先用线性模式调好基础参数
2. 设置 `enable_nonlinear = 1`
3. 从 `nonlinear_k = 1e-7` 开始
4. 大误差响应不够 → 增大到 `1e-6` 或 `1e-5`
5. 出现振荡 → 减小或禁用

**数值示例**（假设 err=200）：
```c
nonlinear_k = 1e-7: 增益 = 1.004 (增强0.4%)
nonlinear_k = 1e-6: 增益 = 1.04  (增强4%)    ⭐ 推荐
nonlinear_k = 1e-5: 增益 = 1.4   (增强40%)   激进
```

### 🔧 内环参数（速度PID）

#### 速度环PID参数
位置：`speed_pid_init(&g_control.cascade_speed_left, ...)`

**默认值**：
```c
kp = 10.0f;   // 比例系数
ki = 0.5f;    // 积分系数
kd = 0.1f;    // 微分系数
integral_max = 100.0f;   // 积分限幅
output_max = 1000.0f;    // PWM限幅
```

**调节步骤**（经典PID调节法）：

##### Step 1: 调节 Kp（比例项）
1. 设置 `ki = 0`, `kd = 0`，只保留 `kp`
2. 从 `kp = 5.0` 开始
3. 观察速度响应：
   - 上升慢/稳态误差大 → kp × 1.5
   - 振荡/超调 → kp × 0.7
4. 找到临界 kp（刚好振荡），取 `kp = 0.6 × kp_临界`

##### Step 2: 加入 Ki（积分项）
1. 在 Step 1 基础上，从 `ki = 0.1` 开始
2. 观察稳态误差：
   - 有稳态误差 → ki × 1.5
   - 响应变慢/振荡 → ki × 0.5
3. 目标：消除稳态误差，无振荡

##### Step 3: 加入 Kd（微分项）
1. 从 `kd = 0.05` 开始
2. 观察超调和振荡：
   - 有超调 → kd × 1.5
   - 响应变慢 → kd × 0.7
3. 目标：快速响应，无超调

**快速调参表**（根据电机功率）：
| 电机类型 | kp | ki | kd |
|----------|----|----|-----|
| 小功率（<10W） | 5~10 | 0.3~0.8 | 0.05~0.15 |
| 中功率（10~30W） | 10~20 | 0.5~1.5 | 0.1~0.3 |
| 大功率（>30W） | 20~50 | 1.0~3.0 | 0.3~0.8 |

**注意事项**：
- 左右轮参数应该**完全相同**（除非电机严重不对称）
- `integral_max` 设为 PWM 的 10~20%
- `output_max` 设为实际 PWM 最大值

---

### 📈 串级PID调参流程图

```
开始
  ↓
1. 先调速度环PID (不接图像)
   - 给定固定速度，调节kp/ki/kd
   - 目标：快速响应，无超调
  ↓
2. 调整 speed_ratio (接入图像)
   - 从小值开始，逐步增大
   - 目标：能回到中线，不振荡
  ↓
3. 调整 max_diff_speed
   - 急弯测试，确保不打滑
  ↓
4. 微调 smooth_alpha
   - 高速时减小，抑制抖动
  ↓
完成
```

## 🧠 方案二：ADRC调参

### 控制结构
```
图像误差 → ADRC → 差速控制量 → 左右轮速度目标
                                    ↓
                              速度环PID → PWM
```

### 参数位置
在 `control.c` 的 `adrc_init()` 函数中

---

### 🔴 必须标定的参数

#### 1. `b` - 系统增益 ⭐⭐⭐⭐⭐ **（必须标定！）**
**物理意义**：控制量到系统输出的增益，约等于 `1 / 轮距`

**默认值**：`7.7f` （假设轮距 13cm）

**标定方法（3选1）**：

##### 方法A：几何法（最简单）
```c
b = 1.0f / wheelbase;  // wheelbase是轮距(米)
```
例如：
- 轮距 10cm → `b = 1/0.10 = 10.0`
- 轮距 13cm → `b = 1/0.13 = 7.7`
- 轮距 15cm → `b = 1/0.15 = 6.7`
- 轮距 20cm → `b = 1/0.20 = 5.0`

##### 方法B：开环测试法（最准确）
1. 修改代码，输出固定差速：
   ```c
   float fixed_diff_speed = 0.5f;  // 0.5m/s差速
   g_control.vL_target = 1.0f - fixed_diff_speed * 0.5f;
   g_control.vR_target = 1.0f + fixed_diff_speed * 0.5f;
   ```

2. 运行小车，测量横向位移速度 `v_lateral` (m/s)
   - 使用上位机记录图像误差变化率
   - 或者用秒表+标尺测量 1 秒内横向移动距离

3. 计算：
   ```c
   b = v_lateral / fixed_diff_speed;
   ```

##### 方法C：在线微调法（动态优化）
1. 用几何法得到初值 `b0`
2. 跑直道，观察响应：
   - 响应慢/误差大 → `b = b × 1.2`
   - 振荡/过冲 → `b = b × 0.8`
3. 反复调整，直到响应快速且稳定

**重要提示**：
- ⚠️ b 值误差超过 50% 会导致 ADRC 失效
- ⚠️ 不同赛道 b 值相同（物理参数）
- ⚠️ 必须实际测量，不要瞎猜

---

#### 2. `h` - 采样时间 ⭐⭐⭐⭐⭐ **（必须精确！）**
**物理意义**：控制循环的实际执行周期（秒）

**默认值**：`0.001f` (1ms)

**设置方法**：
```c
// 如果控制循环是 1ms
h = 0.001f;  // 1ms = 0.001秒

// 如果控制循环是 2ms
h = 0.002f;  // 2ms = 0.002秒

// 如果控制循环是 500μs
h = 0.0005f; // 0.5ms = 0.0005秒
```

**验证方法**：
```c
// 在控制循环中测量实际周期
uint32_t t_start = get_time_us();
control_loop(...);
uint32_t t_end = get_time_us();
float actual_h = (t_end - t_start) / 1000000.0f;
printf("实际h = %.6f\n", actual_h);
```

**重要提示**：
- ⚠️ h 必须与实际控制周期完全一致
- ⚠️ h 误差超过 20% 会导致不稳定
- ⚠️ 修改控制周期必须同步修改 h

---

#### 3. `u_max` - 最大差速限幅 ⭐⭐⭐⭐
**物理意义**：允许的最大差速控制量（m/s）

**默认值**：`1.5f`

**设置方法**：
```c
u_max = v_forward × 1.5f;  // 激进策略
u_max = v_forward × 1.0f;  // 保守策略
```

**调节建议**：
- 与串级PID的 `max_diff_speed` 相同
- 参考前面串级PID的调节方法

---

### 🟡 可调节的性能参数

#### 4. `r` - TD跟踪速度 ⭐⭐⭐⭐
**物理意义**：跟踪微分器的响应速度

**默认值**：`50.0f`

**调节方法**：
- **增大 r**：响应更快，但可能超调
- **减小 r**：响应更平滑，但可能跟不上

**推荐范围**：
- 低速行驶（<1m/s）：`r = 30~50`
- 中速行驶（1~2m/s）：`r = 50~80`
- 高速行驶（>2m/s）：`r = 80~150`

**现象对照**：
| 现象 | 原因 | 调节 |
|------|------|------|
| 目标突变时超调严重 | r 过大 | 减小 30% |
| 响应太慢，跟不上 | r 过小 | 增大 50% |

---

#### 5. `w0` - ESO带宽 ⭐⭐⭐⭐⭐
**物理意义**：扩张状态观测器的带宽，决定抗扰能力

**默认值**：`20.0f`

**调节方法**：
- **增大 w0**：抗扰能力更强，但可能引入噪声
- **减小 w0**：更平滑，但抗扰能力下降

**推荐范围**：
- 平滑赛道：`w0 = 10~20`
- 一般赛道：`w0 = 20~40`
- 颠簸/扰动大：`w0 = 40~100`

**典型场景**：
- 地面不平，小车颠簸 → 增大 w0
- 传感器噪声大 → 减小 w0
- 摩擦力变化大 → 增大 w0

**现象对照**：
| 现象 | 原因 | 调节 |
|------|------|------|
| 受干扰后恢复慢 | w0 过小 | 增大 50% |
| 高频振荡/噪声敏感 | w0 过大 | 减小 30% |
| 坡道/颠簸时失控 | w0 过小 | 增大到 50~80 |

---

#### 6. `kp` 和 `kd` - 位置和速度增益 ⭐⭐⭐
**物理意义**：非线性PD控制器的增益

**默认值**：
```c
kp = 1.0f;   // 位置增益
kd = 0.5f;   // 速度增益
```

**调节方法**（类似PID调节）：
1. **先调 kp**：
   - 增大 kp → 响应快，可能超调
   - 减小 kp → 响应慢，更稳定

2. **再调 kd**：
   - 增大 kd → 减小超调，增加阻尼
   - 减小 kd → 减少阻尼，更灵活

**推荐比例**：
```c
kd = 0.3 ~ 0.7 × kp;  // 经验比例
```

**现象对照**：
| 现象 | 调节方案 |
|------|----------|
| 响应慢，误差大 | kp × 1.3, kd × 1.3 |
| 振荡，不稳定 | kp × 0.7, kd × 1.5 |
| 超调严重 | kd × 1.5 |

---

#### 7. `delta`, `a1`, `a2` - 非线性参数 ⭐⭐
**物理意义**：fal函数的非线性特性参数

**默认值**：
```c
delta = 0.01f;  // 线性区宽度
a1 = 0.5f;      // 位置误差的幂次
a2 = 1.5f;      // 速度误差的幂次（>1增强高频阻尼）
```

**调节建议**：
- **大部分情况下使用默认值即可**
- 如果出现低速死区 → 减小 `delta` 到 0.005
- 如果高频抖动 → 增大 `delta` 到 0.02

### 📈 ADRC调参流程图

```
开始
  ↓
1. 【必须】标定 b 值
   - 测量轮距，b = 1/轮距
   - 或开环测试法
  ↓
2. 【必须】设置 h 值

  ↓

  ↓

  ↓
7. 速度环PID调参

  ↓
完成
```

## ❓ 常见问题与解决方案

### 问题1: 小车直道左右晃动
**可能原因**：
1. **串级PID**：`speed_ratio` 过大
   - 解决：减小到 0.5 倍
2. **ADRC**：`w0` 或 `kp` 过大
   - 解决：减小 30%
3. **共通**：速度环PID的 `kp` 过大
   - 解决：减小速度环 `kp` 到 0.7 倍

---

### 问题2: 入弯冲出赛道
**可能原因**：
1. **串级PID**：`speed_ratio` 过小
   - 解决：增大 1.5~2 倍
2. **ADRC**：`r` 或 `kp` 过小
   - 解决：增大 50%
3. **共通**：`max_diff_speed` / `u_max` 过小
   - 解决：增大到前进速度的 1.5~2 倍

---

### 问题3: 弯道内振荡
**可能原因**：
1. **串级PID**：`speed_ratio` 过大
   - 解决：减小 20%
2. **ADRC**：`w0` 或 `kp` 过大
   - 解决：减小 20~30%
3. **共通**：速度环PID的 `kd` 不足
   - 解决：增大速度环 `kd` 到 1.5 倍

---

### 问题4: 响应太慢，反应迟钝
**可能原因**：
1. **串级PID**：
   - `speed_ratio` 过小 → 增大 50%
   - `smooth_alpha` 过小 → 增大到 0.3~0.5
2. **ADRC**：
   - `r` 过小 → 增大到 80~100
   - `kp` 过小 → 增大 50%
   - `b` 值偏大 → 减小 20%
3. **速度环PID**：
   - `kp` 过小 → 增大 1.5 倍

---

### 问题5: ADRC完全失效，不如PID
**可能原因**：
1. **b 值严重错误** ⚠️
   - 解决：重新标定 b 值
   - 验证：b 应该在 `3~15` 范围内（轮距 6~30cm）
2. **h 值与实际周期不符** ⚠️
   - 解决：用示波器或计时器测量实际周期
3. **w0 过大引入噪声**
   - 解决：减小 w0 到 10~20

---

### 问题6: 左右轮速度不对称
**可能原因**：
1. **电机/编码器不对称**
   - 解决：分别调节左右轮的速度PID参数
   - 左轮 `kp_left`, 右轮 `kp_right` 可以不同
2. **机械安装偏差**
   - 解决：在 `cam_err_calculation()` 中加入零点偏移补偿
   ```c
   float err = cam_err_calculation() - offset;  // offset约为 ±10
   ```

---

### 问题7: 高速时不稳定，低速时正常
**解决方案**：
1. 增大 `smooth_alpha`（串级PID）或减小 `r`（ADRC）
2. 增大速度环 `kd`，抑制高速振荡
3. 减小 `max_diff_speed` / `u_max`，限制转向强度

---

### 问题8: 低速时转向无力，高速时正常
**解决方案**：
1. **串级PID**：增大 `speed_ratio`
2. **ADRC**：增大 `kp` 或检查 `b` 值是否过大
3. **共通**：检查速度环PID是否有死区

## 🎓 调参技巧总结

### 新手推荐路线
1. **先用串级PID**，简单直观
2. 只调 `speed_ratio` 和速度PID的 `kp`
3. 能跑通赛道后，再考虑用ADRC

### 进阶优化路线
1. 用ADRC提高鲁棒性
2. 精确标定 `b` 值（开环测试法）
3. 根据赛道特点调节 `w0` 和 `r`

### 竞赛调参策略
1. **先求稳**：保守参数，确保完赛
   - `speed_ratio = 0.008`
   - `smooth_alpha = 0.15`
   - `max_diff_speed = v_forward × 1.0`

2. **再求快**：激进参数，冲击成绩
   - `speed_ratio = 0.015`
   - `smooth_alpha = 0.25`
   - `max_diff_speed = v_forward × 2.0`

### 在线调参工具推荐
建议使用上位机实时调参：
```c
// 在控制循环中接收上位机数据
if (uart_data_available()) {
    receive_param(&g_control.cascade_diff_params.speed_ratio);
    receive_param(&g_control.adrc_params.w0);
    // ...
}
```
