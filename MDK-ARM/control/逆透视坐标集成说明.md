## 一、新增的逆透视坐标数组

### 在 control.h 中声明（外部可见）

```c
// 逆透视坐标数组(每行存储左右边线的逆透视变换结果)
extern int16_t persp_lx[120];      // 左线逆透视x坐标
extern int16_t persp_rx[120];      // 右线逆透视x坐标
extern uint8_t persp_ly[120];      // 左线逆透视y坐标
extern uint8_t persp_ry[120];      // 右线逆透视y坐标
```

## 二、填充逆透视坐标（修改 persp_task）

### 修改 act_persp.c 的 persp_task 函数

```c
// act_persp.c
void persp_task(int16 xl, int16 xr, int16 y)
{
    int16 oxl, oxr, oyl, oyr;
    
    // 限幅
    if(xl<0) xl=0;
    else if(xl>187) xl=187;
    if(xr<0) xr=0;
    else if(xr>187) xr=187;
    
    // 计算逆透视坐标
    oxl = get_persp_data_ox(xl, y);
    oyl = get_persp_data_oy(xl, y);
    oxr = get_persp_data_ox(xr, y);
    oyr = get_persp_data_oy(xr, y);
    
    // ========== 新增：填充逆透视坐标数组 ==========
    if (y >= 0 && y < 120) {
        persp_lx[y] = oxl;   // 左线逆透视x
        persp_ly[y] = oyl;   // 左线逆透视y
        persp_rx[y] = oxr;   // 右线逆透视x
        persp_ry[y] = oyr;   // 右线逆透视y
    }
    // ========== 新增结束 ==========
    
    // 原有的显示逻辑
    if (img_showmode == 2) {
        imo[y][l_border[y]] = 1;
        imo[y][r_border[y]] = 2;
    }
    // ... 其他显示模式 ...
}
```

### 包含头文件
在 `act_persp.c` 顶部添加：
```c

```

## 三、cam_err_calculation 使用逆透视坐标

### 原始逻辑恢复

现在 `cam_err_calculation()` 已经恢复了基于逆透视坐标的距离判断：

```c
// 跳过过近的行（原逻辑）
if (0.625f * ((int)persp_ly[y] + (int)persp_ry[y]) < cam->forward_near) {
    continue;
}

// 终止条件：该行太远（原逻辑）
if (0.4f * ((int)persp_ly[y] + (int)persp_ry[y]) > cam->forward_far) {
    break;
}
```

### 与原版的对比

| 项目 | 原版 | 简化版(已废弃) | 当前版(恢复) |
|-----|------|--------------|-------------|
| 数据源 | `lineinfo[y].persp_ly/ry` | `l_border[y]` 平均值 | `persp_ly[y]` / `persp_ry[y]` |
| 近端判断 | `0.625*(persp_ly+persp_ry)` | `avg_pos < forward_near` | `0.625*(persp_ly+persp_ry)` |
| 远端判断 | `0.4*(persp_ly+persp_ry)` | `avg_pos > forward_far` | `0.4*(persp_ly+persp_ry)` |
| 优势 | 透视准确 | 简单直接 | **透视准确（推荐）** |

## 四、完整数据流

```
image_process()
    ↓
边线识别 → l_border[y], r_border[y]
    ↓
persp_task(l_border[y], r_border[y], y)  ← 逆透视变换
    ↓
填充数组 → persp_lx[y], persp_ly[y], persp_rx[y], persp_ry[y]
    ↓
cam_err_calculation()  ← 使用逆透视坐标判断距离
    ↓
计算误差 → 输出err
```

## 五、初始化和调用

### main.c 初始化
```c
int main(void)
{
    // 硬件初始化
    HAL_Init();
    
    // 逆透视初始化（必须调用）
    act_perst_init();  // 初始化逆透视查找表
    
    // 控制系统初始化
    cam_err_init(20, 80, 10, 100);
    control_init_cascade_pid_default();
    
    // 启动定时器
    HAL_TIM_Base_Start_IT(&htim_control);
    
    while(1) {
        if (new_image_ready) {
            image_process();  // 内部调用persp_task填充逆透视坐标
            new_image_ready = 0;
        }
    }
}
```

### image_process 调用流程（示例）
```c
void image_process(void)
{
    // 1. 二值化
    binarization();
    
    // 2. 边线识别
    for (int y = 0; y < image_h; y++) {
        // 扫线找到 l_border[y] 和 r_border[y]
        scan_left_right(y);
        
        // 3. 调用逆透视变换（自动填充persp_lx/ly/rx/ry数组）
        persp_task(l_border[y], r_border[y], y);
    }
    
    // 4. 元素识别等其他处理
    // ...
}
```

## 六、参数调整

### forward_near 和 forward_far 含义

原版使用逆透视坐标后，这两个参数的物理意义更明确：

```c
cam_err_init(20, 80, 10, 100);
//           |   |   |    |
//           |   |   |    +-- forward_far: 远端阈值(透视y坐标)
//           |   |   +------- forward_near: 近端阈值(透视y坐标)
//           |   +----------- far_line: 打角终止行(原图y)
//           +--------------- near_line: 打角起始行(原图y)
```

**推荐值**：
- `forward_near = 10`: 跳过透视y < 10的行（太近）
- `forward_far = 100`: 跳过透视y > 100的行（太远）

## 七、常见问题

### Q1: 编译报错 "undefined reference to persp_lx"
**A**: 需要在 `image.c` 或 `act_persp.c` 中定义这些数组：
```c
int16_t persp_lx[120] = {0};
int16_t persp_rx[120] = {0};
uint8_t persp_ly[120] = {0};
uint8_t persp_ry[120] = {0};
```

### Q2: 误差计算结果与原版不一致？
**A**: 检查以下几点：
1. `persp_task()` 是否正确填充了逆透视坐标数组
2. `act_perst_init()` 是否在初始化时调用
3. `forward_near/far` 参数是否合理（建议10和100）

### Q3: persp_ly/ry 全为0？
**A**: 检查 `persp_task()` 调用时机：
- 必须在边线识别后调用
- 必须在 `cam_err_calculation()` 之前调用
- 建议在 `image_process()` 的边线循环中调用

### Q4: 数组越界？
**A**: 确保所有访问都加了边界检查：
```c
if (y >= 0 && y < 120) {
    persp_lx[y] = oxl;
}
```
