# 差速小车控制系统物理建模说明

## 📐 问题分析

### 输入输出关系
- **输入**: `cam_err_calculation()` 返回值
  - 物理意义: 左右边线切线斜率之和 `AngleLeft + AngleRight`
  - 单位: **千分之一弧度** (代码中 `0.001` 的含义)
  - 范围: 约 `±200` (经过 `cam_limit` 限幅)
  
- **输出**: 左右轮速度 `vL`, `vR`
  - 物理意义: 轮子线速度
  - 单位: `m/s`

- **已知参数**: 
  - `half_track` (半轮距 L): 0.065m (13cm 轮距)

---

## 🔧 运动学推导

### 1. 差速小车基础运动学

差速小车的左右轮速度关系:
$$
\begin{cases}
v_L = v - \omega \cdot L \\
v_R = v + \omega \cdot L
\end{cases}
$$

其中:
- $v$: 前进速度 (m/s)
- $\omega$: 角速度 (rad/s)
- $L$: 半轮距 (m)

**差速定义**:
$$
\Delta v = v_R - v_L = 2\omega L
$$

因此:
$$
\omega = \frac{\Delta v}{2L}
$$

## 📊 串级PID方案的映射公式

### 原理说明

`cam_err_calculation()` 返回的切线斜率和反映了**期望的转向角速度**:
- 误差为正 → 左边线斜率大(左转弯) → 需要右转修正
- 误差为负 → 右边线斜率大(右转弯) → 需要左转修正

### 映射公式推导

#### Step 1: 误差归一化
```c
err_normalized = err / 1000.0f;  // 千分之一 → 弧度
```

#### Step 2: 误差转角速度
```c
omega = K_err × err_normalized;  // K_err是增益,单位: rad/s per rad
```

其中 `K_err` (即代码中的 `speed_ratio`) 的物理意义:
- **期望的误差响应速度**
- 误差为 1 弧度时,期望的转向角速度
- 典型值: `5~15 rad/s`

#### Step 3: 角速度转差速
```c
speed_diff = omega × half_track;  // 运动学关系
```

### 完整公式

```c
// 物理映射公式
float err = cam_err_calculation();           // 获取误差(千分之一弧度)
float omega = speed_ratio × (err / 1000.0f); // 误差→角速度
float speed_diff = omega × half_track;       // 角速度→差速
```

等效为:
$$
\Delta v = K_{err} \cdot \frac{err}{1000} \cdot L
$$

### 参数调节指南

#### `speed_ratio` (误差→角速度增益)

**物理意义**: 当误差为 1 弧度(约57度)时,期望的转向角速度

**推荐值**:
- 保守: `speed_ratio = 5.0` → 误差1rad时转向5rad/s(约286度/秒)
- 适中: `speed_ratio = 10.0` → 误差1rad时转向10rad/s(约573度/秒) ⭐
- 激进: `speed_ratio = 15.0` → 误差1rad时转向15rad/s(约860度/秒)

**调节方法**:
1. 从 `speed_ratio = 5.0` 开始
2. 直道测试,如果回正慢 → 增大到 10.0
3. 弯道测试,如果振荡 → 减小 20%

**注意**: 这个参数比原来的 `0.01` 增大了1000倍,因为引入了物理单位转换!

#### `half_track` (半轮距)

**必须精确测量!**
```c
half_track = 轮距(米) / 2;
```

例如:
- 10cm 轮距 → `half_track = 0.050`
- 13cm 轮距 → `half_track = 0.065` ⭐
- 15cm 轮距 → `half_track = 0.075`

## 🧠 ADRC方案的物理建模

### 系统模型

ADRC需要建立 `误差err` 到 `角速度ω` 的系统模型:

$$
\frac{d(err)}{dt} = -K \cdot \omega + f(t)
$$

其中:
- $K$: 系统响应增益 (ADRC的b参数)
- $f(t)$: 总扰动(摩擦力、坡度、风阻等)

**物理解释**:
- 当给定角速度 $\omega$ 时,横向误差 $err$ 会以 $K\omega$ 的速度减小
- $K$ 越大,系统响应越快

### b参数标定方法

#### 方法1: 开环测试法(最准确) ⭐⭐⭐⭐⭐

**步骤**:
1. 让小车在直道中央
2. 给定固定角速度 `omega_test = 5.0 rad/s` (约286度/秒)
3. 测量横向误差变化率 `d_err/dt` (用上位机记录误差曲线的斜率)
4. 计算:
   ```c
   b = (d_err / dt) / omega_test;
   ```

**示例**:
- 给定 `omega = 5.0 rad/s`
- 测得误差以 `25 (千分之一弧度/秒)` 的速度减小
- 则 `b = 25 / 5.0 = 5.0`

#### 方法2: 经验估计法

根据小车参数估计:
$$
b \approx \frac{v_{forward}}{L \cdot err_{typical}}
$$

其中:
- $v_{forward}$: 典型前进速度 (如1.0 m/s)
- $L$: 半轮距 (如0.065 m)
- $err_{typical}$: 典型误差范围 (如50)

**计算示例**:
```c
b = 1.0 / (0.065 × 50 / 1000) = 307 / 1000 ≈ 3~10 (数量级)
```

**推荐范围**: `b = 3~10`

#### 方法3: 在线调节法

1. 从 `b = 5.0` 开始
2. 跑直道观察:
   - 响应慢/误差大 → `b × 1.3`
   - 振荡/不稳定 → `b × 0.7`

### u_max参数

**物理意义**: 最大允许角速度 (rad/s)

**设置方法**:
$$
\omega_{max} = \frac{\Delta v_{max}}{2L}
$$

其中 $\Delta v_{max}$ 是最大差速 (如1.5 m/s):
$$
\omega_{max} = \frac{1.5}{2 \times 0.065} = 11.5 \text{ rad/s} \approx 660 °/s
$$

**推荐值**:
```c
u_max = 15.0f;  // 约860度/秒,激进转向
u_max = 10.0f;  // 约573度/秒,适中转向
u_max = 5.0f;   // 约286度/秒,保守转向
```

## 🔬 验证方法

### 单位验证

**串级PID**:
```c
err = 100;                      // 千分之一弧度
omega = 10.0 × (100/1000);      // = 1.0 rad/s = 57度/秒
speed_diff = 1.0 × 0.065;       // = 0.065 m/s
```
✅ 单位正确: `m/s`

**ADRC**:
```c
err = 100;                      // 千分之一弧度
omega = adrc_control_core();    // 返回 rad/s
speed_diff = omega;             // 直接是 rad/s(需要后续处理)
```

### 物理合理性验证

**典型场景**: 直道偏离50个单位
```c
err = 50;                       // 约0.05弧度 = 2.86度
omega = 10.0 × 0.05 = 0.5 rad/s // 约28.6度/秒(合理)
speed_diff = 0.5 × 0.065 = 0.0325 m/s // 3.25cm/s的差速(合理)
```

✅ 响应速度适中,不会过激

## 📝 总结

### 核心改进

1. **引入物理单位转换**: `err / 1000` 将千分之一弧度转为弧度
2. **使用运动学公式**: `Δv = ω × L` 符合差速小车物理模型
3. **参数物理意义明确**: 
   - `speed_ratio` = 误差1弧度时的转向角速度
   - `b` = 系统响应增益(需标定)
   - `u_max` = 最大角速度(ADRC)

### 优势

- ✅ 参数可跨平台迁移(基于物理模型)
- ✅ 调参有明确物理指导(不再盲调)
- ✅ 支持不同轮距的小车(只需修改 `half_track`)
- ✅ 公式推导清晰,易于理解和改进

### 注意事项

⚠️ **重要**: 修改后 `speed_ratio` 的数值范围变化(从0.01→10.0),需要重新调参!
⚠️ **必须**: 精确测量 `half_track` 参数
⚠️ **ADRC**: 必须标定 `b` 值,否则可能完全失效
